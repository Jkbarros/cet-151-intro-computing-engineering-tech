# Repository guide — CET 151

Coursework is organized by **unit folders** at the repository root (Canvas export layout).

| Folder pattern | Typical contents |
|----------------|------------------|
| `Unit 1` … `Unit 14`, `Unit11`, `Unit7` | MATLAB (`.m`), Excel (`.xlsx` / `.xlsm`), occasional C++ (`.cpp`) |
| `Test`, `Test 1`, `T3` | Tests and checkpoints |
| `Unit 1 JBarros` | Named unit submission |

## File types

- **`.m`** — MATLAB scripts and functions  
- **`.xlsx` / `.xlsm`** — spreadsheet labs (macros in `.xlsm`)  
- **`.cpp`** — C++ exercises (compile locally; `.exe` binaries are gitignored)

## Tips

- Search the repo for `.m` or `.cpp` to jump to code quickly.
- Large binaries and build outputs are excluded via `.gitignore` (`*.exe`).
